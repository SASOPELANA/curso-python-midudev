# Curso de Python - Midudev

Curso de Python, dictado por el Youtuber Midudev. En este curso se cubren los fundamentos de Python, incluyendo variables, tipos de datos, estructuras de control, funciones, módulos y mucho más. Es un curso ideal para principiantes que quieren aprender a programar en Python desde cero.

## Contenido del curso

### 01_basic - Fundamentos
- Impresión de mensajes con `print()`
- Tipos de datos y `type()`
- Casting y conversión de tipos
- Variables y f-strings
- Entrada de datos con `input()`
- Ejercicios y soluciones para practicar los conceptos básicos

### 02_flow_control - Control de flujo
- Condicionales `if`, `elif` y `else`
- Operadores lógicos (`and`, `or`, `not`)
- Condiciones ternarias
- Booleanos
- Listas: creación, indexación, slicing y métodos

### 03_loops - Bucles
- Bucle `while`
- Bucle `for`
- Función `range()`
- Funciones y su definición
- Ejercicios con soluciones para cada tema

### 04_logic - Lógica
- Retos y desafíos de lógica de programación (ej: contar ocurrencias y verificar equilibrio)

## Estructura del repositorio

```
curso-python-midudev/

├── 03_loops/            # Bucles, range() y funciones
├── 04_logic/            # Retos de lógica
└── README.md
```

## Requisitos

- Python 3.x instalado en tu sistema

## Cómo ejecutar los ejemplos

```bash
python 01_basic/01_print.py
python 02_flow_control/01_if.py
python 03_loops/01_loop_while.py
```

Cada archivo es un script independiente que puedes ejecutar por separado para ver su salida y entender los conceptos.
